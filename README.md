# Vesto Catálogo

White-label de catálogo digital para atacado de moda. Painel admin com preview interativo do catálogo.

## Stack

- Next.js (App Router)
- Tailwind CSS
- TypeScript

## Local

```bash
npm install
npm run dev
```

## Deploy

Pronto para Vercel: conecte `https://github.com/Leonardotrentini/catalogo.git` e faça deploy da branch `main`.
